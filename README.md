# AEM Where Is What

Follow the content. Find the evidence.

AEM Where Is What helps you investigate the source of selected webpage content using exposed CMS metadata and local data evidence. This repository contains public product information and the privacy policy.

- [Homepage](https://javadtaghia.github.io/domtrail/)
- [Privacy policy](https://javadtaghia.github.io/domtrail/privacy.html)
- [Support](https://github.com/javadtaghia/domtrail/issues)

Do not include private website content, internal URLs or credentials in support reports.
