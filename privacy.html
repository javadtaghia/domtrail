DOMtrail privacy policy

Effective 13 November 2026.

DOMtrail — Web Source Inspector helps you investigate the source of selected webpage content. Analysis runs locally in your browser. The extension has no developer-operated analysis server, analytics, advertising, or telemetry.

Information used for inspection

After you start inspection, DOMtrail examines the current page's visible content, element attributes, exposed CMS metadata, eligible embedded JSON, resource URLs, and experiment metadata. It uses this information to show source evidence and candidate data fields. It does not deliberately read typed form values, passwords, or payment input. A page's own embedded data can contain sensitive information; inspect pages and share diagnostic details with care.

Inspection also uses the element you select, pointer position to draw the inspection highlight, and the page's resource list when needed for deep scan. Pointer movements and keystrokes are not retained as an activity log.

Information stored on your device

Chrome extension local storage holds your settings, optional AEM author profiles, routing rules, field source rules, deep scan preferences, and a compact summary of the most recent inspection. That summary may include a source label, element description, CMS resource path, page URL without its query or fragment, and inspection time. Full embedded payloads and matched values are not saved as the last result. This storage is not synced by the extension or sent to the developer.

Optional network access

Deep scan is off by default. If you start it, or explicitly enable automatic deep scan for sites you inspect, the extension may re-request resources from the inspected website, including its HTML, data responses, and scripts. These requests omit credentials and cookies. The website may receive ordinary connection information such as your IP address and requested URL. Downloaded scripts are examined as text, not executed as extension code. DOMtrail does not send page content to an external analysis service.

Opening an optional AEM author link navigates your browser to the author environment you configured. That website's own authentication and privacy practices apply. DOMtrail does not collect your AEM password or store login credentials.

Permissions

activeTab grants temporary access to the page you choose to inspect. scripting runs the bundled inspector on that page. storage saves local preferences and the recent result summary. The extension requests no permanent access to all websites.

Sharing and data use

The developer does not receive, sell, or share inspection data. Data is used only for the extension's source inspection features, never advertising, unrelated profiling, creditworthiness, or lending. Use of information received through Google APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements.

Your choices

Press Escape or close the inspector to stop inspection. Deep scan preferences can be changed in settings. Resetting to generic settings removes configured profiles and rules; uninstalling the extension removes its local extension storage, including the recent result summary. Do not include sensitive page data when contacting support.
